Frequently Asked Questions

Jawaban atas pertanyaan yang paling sering diajukan calon klien kami.

Kenapa bisa gratis biaya hosting dan server selamanya?

Kami memanfaatkan static web hosting tingkat dunia (seperti GitHub Pages / Vercel Cloud) yang menyediakan kuota gratis tanpa batas waktu untuk web modern. Untuk urusan backend & database, kami integrasikan dengan Google Cloud Apps Script dan Google Spreadsheet.

Apakah saya tetap bisa pakai domain bisnis saya sendiri (.com / .id)?

Tentu saja! Jika kamu sudah punya nama domain sendiri atau ingin beli nama domain (misal: tokoanda.com), kami akan bantu setting sambungkan domain tersebut ke websitemu tanpa biaya tambahan server.

Berapa lama proses pembuatannya?

Untuk paket Starter dan Landing Page standar, rata-rata selesai dalam 1 hingga 3 hari kerja setelah materi (teks/foto) lengkap. Untuk kebutuhan custom tools atau automasi khusus biasanya memakan waktu 3-7 hari kerja.

Apakah data pelanggan saya di Google Sheet aman?

Sangat aman karena Google Spreadsheet tersebut berada langsung di dalam akun Google (Google Drive) milikmu sendiri. Hanya akun Google yang kamu beri izin yang bisa membuka atau mengakses datanya.
